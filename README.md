## CloudWay RAG — Week 5 Community Contribution

### What's included

* LangChain-based RAG implementation
* CloudWay 24 airline knowledge base
* 40+ PDF documents covering flights, baggage, policies, passenger assistance, and other airline information
* Hugging Face `all-MiniLM-L6-v2` embeddings
* Chroma vector database
* Groq LLM integration
* `ingest.py` for document ingestion and vector database creation
* `answer.py` for retrieval and question answering
* Gradio application for interacting with the RAG assistant
* Project README and requirements
